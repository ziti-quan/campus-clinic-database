# 前端截图工具使用说明

## 为什么需要你本地跑一次

AI 运行在一个受限沙箱里，Edge / Chrome / QtWebEngine 这类 Chromium 浏览器
在该沙箱内**无法启动**（创建浏览器数据目录与 Mojo 命名管道被拒绝，
报 `platform_sandbox.cc` / `platform_channel.cc` FATAL）。
所以“真实网页截图”这件事必须在沙箱之外、由你本机执行。

## 用法

1. 确认已安装依赖（`pip install -r requirements.txt`），并已导入数据库：

   ```
   mysql -h 127.0.0.1 -P 3308 -u root -p < schema.sql
   mysql -h 127.0.0.1 -P 3308 -u root -p hospital < seed_data.sql
   ```

2. **双击 `一键截图.bat`**（或在命令行执行 `python auto_shoot.py`）。

   > 批处理窗口是英文界面，这是刻意的：`.bat` 只能保存为纯 ASCII 才能避免
   > cmd.exe 用 GBK 代码页解析时出现乱码。中文提示与最终路径由 Python 脚本打印。
   > 如果批处理仍无法运行，直接在该目录打开命令行执行 `python auto_shoot.py` 即可。

脚本会自动完成：

- 检查 5000 / 5001 / 5002 三个服务，未启动则自动拉起（截图结束后关闭它拉起的进程）
- 用 Edge 无头模式 + CDP 自动登录患者端与医生端
- 自动切换“我的挂号 / 病历 / 药单 / 当日患者 / 药品库存 / 排班 / 处方 / 管理端四个页签”等视图
- 把 20 张截图写入 `../截图/网页截图/`

## 前置条件

| 项目 | 要求 |
|---|---|
| Python | 3.9+，需有 `requests` 与 `websocket-client`（Anaconda 自带） |
| 浏览器 | 已安装 Microsoft Edge（Win10/11 自带） |
| 数据库 | MySQL 已运行，`hospital` 库已按 `schema.sql` 建表并导入 `seed_data.sql` |
| 演示数据 | 至少有一条“陈晨 → 张伟”的挂号记录（运行 `seed_data.sql` 后再走一遍患者挂号即可） |

## 如果脚本报错

| 现象 | 处理 |
|---|---|
| 双击后出现 `'xx' 不是内部或外部命令` 之类的乱码报错 | 这是旧版批处理用 UTF-8 存中文导致的，现已改为纯 ASCII + CRLF；请确认使用的是最新版 `一键截图.bat`。或直接用 `python auto_shoot.py` |
| 提示缺少 `websocket` 或 `requests` | `pip install requests websocket-client` |
| 提示未找到 Edge | 修改 `auto_shoot.py` 顶部的 `EDGE_CANDIDATES`，填入本机 Edge 路径 |
| 提示“与浏览器的调试通道断开” | 把 `auto_shoot.py` 里 Edge 启动参数中的 `--headless=new` 改成 `--headless` 再试 |
| 登录失败 | 确认已导入 `seed_data.sql`，且患者/医生的口令仍是默认的 `123456` |
| 看不到数据 | 先按 README 的“演示动线”走一遍：患者挂号 → 医生写病历/开处方 |
